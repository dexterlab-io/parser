DexterLab Glossary
(Versione 2026 — Unified Command Ecosystem Terminology)

This glossary defines all core terms used in the DexterLab command ecosystem,
including parser terminology, backend semantics, bus concepts, error codes,
memory regions, and master/arbiter behavior.

It is the recommended reference for new users, contributors, and hardware
integrators.

1. Command Interface Terms
t_cmd_out
Structured command generated by the parser or hardware master.
Contains: write/read flag, burst/wrap/FIFO flags, atomic flag, address, length,
data array, WSTRB mask, command ID.

t_rsp_in
Response structure generated by the backend.
Contains: valid flag, last beat flag, read data, error flags, error code, error
info, response ID.

cmd_valid / cmd_ready
Handshake signals for command acceptance.
Command is accepted when both are 1.

rsp_valid / rsp_ready
Handshake signals for response beats.

rsp_last
Indicates the final beat of a multi‑beat response.

2. Command Types
WRITE
Writes a single 32‑bit word.

READ
Reads a single 32‑bit word.

CHECK
Reads a word and compares it with an expected value.

BURST_WRITE / BURST_READ / BURST_CHECK
Multi‑beat INCR burst operations.

WRAP_WRITE / WRAP_READ / WRAP_CHECK
Wrap burst operations using modulo addressing.

FIFO_WRITE / FIFO_READ / FIFO_CHECK
Push/pop operations on FIFO endpoints.

POLL_READ / POLL_TOGGLE / POLL_PING
Repeated read operations until a condition is met or timeout occurs.

DUMP_LEN / DUMP_RANGE
Reads memory and prints values.

DUMP_FILE_LEN / DUMP_FILE_RANGE
Reads memory and writes values to a file.

DUMP_FILE_CHECK_LEN / DUMP_FILE_CHECK_RANGE
Reads memory and compares values with a reference file.

SET_VAR
Defines a variable for address or data expressions.

INCLUDE
Loads another .cmd file.

3. Command Flags
cmd_write
1 = write, 0 = read.

cmd_burst
Indicates multi‑beat INCR burst.

cmd_wrap
Indicates wrap burst.

cmd_fifo
Indicates FIFO operation.

cmd_atomic
Locks the arbiter to prevent interleaving.

cmd_len
Number of beats (1–256).

cmd_wstrb
Byte mask for partial writes.

cmd_id
Unique command identifier for matching responses.

4. Memory Regions
REG Region
0x0000–0x001F  
Eight 32‑bit registers.
Single‑beat only.

RAM Region
0x1000–0x2FFF  
Contiguous memory block.
Supports burst, wrap, WSTRB, FIFO semantics.

FIFO Region
0x3000 → FIFO_WRITE
0x3100 → FIFO_READ
Streaming push/pop operations.

5. Burst and Wrap Semantics
INCR Burst
Address increments by 4 bytes per beat.

WRAP Burst
Address wraps around a mask:

Codice
mask = len * 4 bytes
wrap_base = addr & ~(mask - 1)
wrapped_addr = wrap_base + (offset % mask)
4KB Boundary Rule
Bursts cannot cross a 4KB boundary.
Parser splits bursts automatically.

6. FIFO Semantics
FIFO_WRITE
Pushes data into FIFO.

FIFO_READ
Pops data from FIFO.

FIFO_CHECK
Reads FIFO and compares values.

Underflow
Reading from empty FIFO → SLVERR.

Overflow
Writing beyond FIFO capacity → SLVERR.

7. Error Codes
OKAY (0x00)
Operation successful.

SLVERR (0x02)
Backend error (FIFO underflow, overflow, protocol violation).

DECERR (0x03)
Address outside valid regions.

BOUNDARY_ERR (0x06)
Burst crosses 4KB boundary.

BURST_ERR (0x07)
Invalid burst or wrap semantics.

8. Arbiter Terms
Pending Command
A command accepted but not yet completed.

Atomic Mode
Locks arbiter to current source.

Parser Source
Commands generated from .cmd files.

Master Source
Commands generated by hardware master (RISC‑V, DMA, FPGA logic).

Source Switching
Arbiter chooses parser or master based on pending flags and atomic mode.

9. Backend Terms
Backend Executor
Module that converts t_cmd_out into bus transactions.

AXI‑FULL Backend
Full AXI4 protocol.

AXI‑LITE Backend
Single‑beat AXI‑Lite protocol.

AHB‑FULL Backend
Full AHB protocol.

AHB‑LITE Backend
Simplified AHB protocol.

Generic Backend
Pure VHDL simulation backend.

TileLink Bridge
Converts TileLink UL/UH transactions into t_cmd_out.

10. Parser Internals
Tokenizer
Splits text into tokens.

Syntax Parser
Matches tokens to command templates.

Semantic Validator
Checks address, length, burst, wrap, FIFO, polling semantics.

Burst Splitter
Splits bursts >256 or crossing 4KB boundary.

Wrap Calculator
Computes wrap mask and wrapped addresses.

Variable Engine
Handles numeric variables and expressions.

Include Engine
Loads additional .cmd files.

Polling Engine
Generates repeated reads until condition met.

Dump Engine
Reads memory and prints or writes to file.

11. Testbench Terms
tb_dexterlab
Main simulation testbench.

Waveform Dump
VCD/FST/XSIM output for debugging.

DRY_RUN Mode
Parses commands without executing them.

Memory Models
REG, RAM, FIFO simulation blocks.

12. Master Terms
cmd_master
Placeholder hardware master.

RISC‑V Master
Future master generating TileLink → t_cmd_out.

DMA Master
Future master generating burst commands.

Remote Master (RCP)
Future Ethernet/T1S remote command generator.
